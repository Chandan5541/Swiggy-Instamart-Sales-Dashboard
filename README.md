# Swiggy Instamart Sales Dashboard

## Business Problem
Management wanted one view of retail performance: which city types, shop sizes and shop types drive sales, which shops perform best, and how sales change by quarter.

## Dashboard


![Swiggy Instamart Sales Dashboard](YOUR_IMAGE_NAME.png)



## What I Built
An interactive Power BI dashboard with KPIs (Total Sales, Total Orders, Average Order Value, Average Rating), sales by city type and shop size, orders by shop type, a quarterly sales trend, a Top 5 shops leaderboard and a year slicer.

## Tools Used
Power BI, DAX, Power Query

## Key Insights
- Total sales of about 439K from 2K orders, with an average order value of 183.80
- Supermarket Type1 contributes about 74% of sales, far ahead of Grocery Stores
- SHOP052, SHOP017 and SHOP059 are the top performing shops
- Average customer rating is 3.92

## Learnings
Custom DAX measures, choosing the right KPIs and using Top N filters.
